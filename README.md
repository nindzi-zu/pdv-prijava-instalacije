# PDV prijava - AI asistent — instalacije

Ovdje se objavljuju **gotove instalacije** aplikacije *PDV prijava - AI asistent*
(Windows). Kod aplikacije nije javan.

## Instalacija

1. Otvori [najnovije izdanje](../../releases/latest) i preuzmi
   `PDV_prijava_AI_asistent_Setup_<verzija>.exe`.
2. Pokreni ga. Windows može prikazati „Windows je zaštitio vaš računar“
   (program još nije digitalno potpisan) → **Više informacija → Pokreni svejedno**.
3. Instalacija ne traži administratorska prava. Na desktopu se pojavi ikonica.

Potreban je **Microsoft Excel** (knjige su postojeći .xls obrasci) i Windows 10/11.

## Ažuriranje

Aplikacija sama provjeri ima li novije izdanje ovdje i javi (Postavke → O programu).
Instalira se tek kad klikneš **Ažuriraj**. Ažuriranje mijenja samo program —
firme, knjige i fakture ostaju netaknute.
